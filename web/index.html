DISPLAY

Virtual OLED 128 x 64
Updating 0%
OLED disabled

Button 1 defaults to GPIO5. Button 2 defaults to GPIO6 on ESP32-S3 builds and GPIO18 on regular ESP32 builds, because GPIO6 is part of the flash bus on ESP32. Both inputs are treated as active-high touch/button inputs, and the Home Assistant Previous and Next actions publish MQTT events on the button-action topic so you can bind those touches to Home Assistant automations. When rotated 90 or 270 degrees the renderer automatically uses the effective portrait resolution so text and OTA progress fit the rotated screen. OLED SDA, SCL, and RESET must not reuse the active I2S pins used by the MAX98357A.

When triggered, the selected GPIO is pulled low for 500 ms and then driven high again.

Available GPIOs exclude the active I2S pins, the battery ADC pin used for battery/charging sensing, and the current WS2812/status LED pin.

MQTT command topic: BASE_TOPIC/cmd/display_trigger. Home Assistant discovery exposes this as a button named Display Trigger.
