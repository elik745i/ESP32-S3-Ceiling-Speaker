ELMA IoT v0.1.36

- ELMA Flasher now uses one native window with Device Designer and Flash USB Device tabs at the top.
- Device Designer opens by default instead of launching from a separate flasher window.
- Switching to Flash USB Device saves the complete live designer form, including Wi-Fi fields, into the shared local configuration backend.
- Compile and Flash reads that shared configuration at click time, preventing stale settings from being built or provisioned.
- The Flash USB Device tab is focused on target selection, maximum-fit capabilities, erase policy, progress, logs, cancellation, compilation, flashing and provisioning.
