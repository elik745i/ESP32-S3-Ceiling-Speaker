ELMA IoT v0.1.33

- Device Designer now opens inside a native ELMA application window instead of the system browser.
- The portable executable bundles Qt WebEngine, so Designer does not require Edge, WebView2, Chrome, Web Serial, Python, PlatformIO, or other installed utilities.
- Closing Designer returns to the main ELMA Flasher window.
- The existing full Designer interface, graphical peripheral configuration, chip selection, local compilation, COM-port flashing, progress, cancellation, and provisioning remain connected to the internal loopback-only backend.
- Packaged release validation loads the complete Designer page through the bundled native renderer.
